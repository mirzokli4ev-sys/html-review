Text formatting tags

These tags structure and emphasize text: headings, paragraphs, bold, italic, line breaks and more.

<h1> … <h6>

Definition

Six levels of headings. <h1> is the most important title, <h6> the least.

Attributes

AttributeRole
(global)Only global attributes such as id and class.

Example (code)

<h1>Title</h1>
<h2>Subtitle</h2>
<h3>Section</h3>

Example (result)

Title

Subtitle

Section

<p>

Definition

Defines a paragraph of text. Browsers add space above and below it.

Attributes

AttributeRole
(global)Only global attributes.

Example (code)

<p>This is a paragraph of text.</p>

Example (result)

This is a paragraph of text.

<strong>, <b>, <em>, <i>

Definition

<strong> marks important text (bold), <b> is visually bold, <em> gives emphasis (italic), <i> is visually italic.

Attributes

AttributeRole
(global)Only global attributes.

Example (code)

<strong>Important</strong> and <em>emphasized</em> text.

Example (result)

Important and emphasized text.

<br> and <hr>

Definition

<br> inserts a single line break. <hr> draws a horizontal dividing line. Both are empty tags (no closing tag).

Attributes

AttributeRole
(global)Only global attributes; presentational size/color is done with CSS.

Example (code)

Line one<br>Line two
<hr>

Example (result)

Line one
Line two

<span>, <mark>, <sup>, <sub>

Definition

<span> is an inline container for styling part of text. <mark> highlights text. <sup> makes superscript, <sub> subscript.

Attributes

AttributeRole
class / idUsed to target the element with CSS.

Example (code)

H<sub>2</sub>O and E = mc<sup>2</sup>.
<mark>Highlighted</mark> word.

Example (result)

H2O and E = mc2. Highlighted word.
