Metadata

Metadata tags live inside <head>. They are not displayed in the page, but give the browser and search engines information about it.

<meta>

Definition

Provides metadata such as the character set, the page description or the viewport. It is an empty tag placed in the <head>.

Attributes

AttributeRole
charsetSets the character encoding, usually UTF-8.
nameType of metadata: description, author, viewport…
contentThe value linked to the name.

Example (code)

<meta charset="UTF-8">
<meta name="description" content="A page about HTML tags.">
<meta name="viewport" content="width=device-width, initial-scale=1.0">

Example (result)

These <meta> tags are in the <head> of this page — open the source to see them.

<title>

Definition

Sets the title of the page, shown in the browser tab and used by search engines.

Attributes

AttributeRole
(none)No attributes; the title is the text between the tags.

Example (code)

<title>HTML Review — Metadata</title>

Example (result)

Look at your browser tab: it shows HTML Review — Metadata.

<link>

Definition

Links an external resource to the page — most often the CSS stylesheet or a favicon. It is an empty tag in the <head>.

Attributes

AttributeRole
relRelationship, e.g. stylesheet or icon.
hrefPath of the linked file.
typeMIME type of the resource (optional).

Example (code)

<link rel="stylesheet" href="css/style.css">
<link rel="icon" href="images/favicon.png">

Example (result)

The style of every page here is loaded with a <link rel="stylesheet">.

<base>

Definition

Sets a base URL for all relative links in the page. Placed once in the <head>.

Attributes

AttributeRole
hrefThe base URL used for every relative link.
targetDefault target for all links (e.g. _blank).

Example (code)

<base href="https://example.com/">

Example (result)

With a <base>, a link like page.html would point to https://example.com/page.html.
