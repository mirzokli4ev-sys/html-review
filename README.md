# HTML Review

A multi-page website that reviews the main HTML tags. Built with plain HTML and one
external CSS file (no inline styles, no `<style>` tag).

## Structure
- `index.html` — Home & page structure (DOCTYPE, html, head, body)
- `text.html` — Text formatting tags
- `links.html` — Links & images
- `lists.html` — Lists
- `tables.html` — Tables
- `forms.html` — Forms
- `media.html` — Multimedia (audio, video, iframe)
- `semantic.html` — Semantic & layout tags
- `metadata.html` — Metadata (meta, title, link, base)
- `css/style.css` — shared stylesheet (Flexbox nav, box model, colors)
- `images/` — media files

Each tag is presented with three parts: **Definition**, an **Attributes** table,
and an **Example** shown twice (as code with `&lt;` / `&gt;` entities, and as the real
result in the browser).

## Run
Open `index.html` with Live Server in VS Code, or:
```
python3 -m http.server 8000
```
