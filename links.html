Links and images

The anchor tag connects pages together, and the image tag embeds pictures.

<a>

Definition

The anchor tag creates a hyperlink to another page, a section, an email or a file.

Attributes

AttributeRole
hrefThe destination URL or path of the link.
targetWhere to open the link, e.g. _blank for a new tab.
titleTooltip text shown on hover.
relRelationship, e.g. noopener for security.

Example (code)

<a href="https://example.com" target="_blank">Visit Example</a>

Example (result)

Visit Example

<img>

Definition

Embeds an image in the page. It is an empty tag (no closing tag).

Attributes

AttributeRole
srcThe path or URL of the image file.
altAlternative text shown if the image fails to load (and for accessibility).
widthThe width of the image in pixels.
heightThe height of the image in pixels.

Example (code)

<img src="images/sample.jpg" alt="A modern house" width="300">

Example (result)

<a> around an <img>

Definition

An image can become a clickable link by placing <img> inside an <a>.

Attributes

AttributeRole
hrefDestination of the clickable image.
altDescribes the image inside the link.

Example (code)

<a href="index.html">
  <img src="images/sample.jpg" alt="Go home" width="150">
</a>
