Forms

Forms collect information from the user with inputs, labels, text areas and buttons.

<form>

Definition

The container that groups form controls and sends their data to a server.

Attributes

AttributeRole
actionThe URL that receives the submitted data.
methodHow data is sent: get or post.

Example (code)

<form action="/send" method="post"> ... </form>

Example (result)

A form wraps all the controls below.

<label> and <input>

Definition

<input> is a control that accepts data. <label> gives it a clickable text label. <input> is an empty tag.

Attributes

AttributeRole
typeKind of field: text, email, password, checkbox, radio, number…
nameThe key sent with the value to the server.
placeholderHint text shown inside an empty field.
requiredMakes the field mandatory.
for (on label)Links the label to an input by its id.

Example (code)

<label for="mail">Email</label>
<input type="email" id="mail" name="mail" placeholder="you@mail.com" required>

Example (result)

<textarea>, <select>, <option>, <button>

Definition

<textarea> is a multi-line text box. <select> is a drop-down menu made of <option> items. <button> triggers an action.

Attributes

AttributeRole
rows / colsSize of the <textarea>.
value (option)The data sent when that option is chosen.
type (button)submit, reset or button.

Example (code)

<textarea rows="3"></textarea>
<select>
  <option value="a">Option A</option>
  <option value="b">Option B</option>
</select>
<button type="submit">Send</button>
