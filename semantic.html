Semantic and layout tags

Semantic tags describe the meaning of a page region, which helps accessibility and SEO.

<header>, <nav>, <footer>

Definition

<header> is the top area (title/logo), <nav> holds the main navigation menu, and <footer> is the bottom area (credits, links).

Attributes

AttributeRole
(global)Only global attributes; they have meaning, not special attributes.

Example (code)

<header>Site title</header>
<nav><a href="#">Home</a></nav>
<footer>© 2026</footer>

Example (result)

This very page uses a <header>, a <nav> and a <footer>.

<main>, <section>, <article>, <aside>

Definition

<main> is the primary content, <section> is a thematic group, <article> is a self-contained piece, and <aside> is side content.

Attributes

AttributeRole
(global)Only global attributes.

Example (code)

<main>
  <section>
    <article>A blog post</article>
  </section>
  <aside>Related links</aside>
</main>

Example (result)

A blog post — this is an <article>.

<figure> and <figcaption>

Definition

Groups a media element (like an image) with its caption.

Attributes

AttributeRole
(global)Only global attributes.

Example (code)

<figure>
  <img src="images/sample.jpg" alt="House" width="200">
  <figcaption>A modern villa.</figcaption>
</figure>

Example (result)
