Tables

Tables display data in rows and columns using a group of related tags.

<table>, <tr>, <td>, <th>

Definition

<table> is the container, <tr> is a table row, <td> is a data cell and <th> is a header cell (bold, centered).

Attributes

AttributeRole
colspanMakes a cell span several columns.
rowspanMakes a cell span several rows.
scopeOn <th>: tells if it heads a row or a col.

Example (code)

<table>
  <tr><th>Name</th><th>Age</th></tr>
  <tr><td>Sara</td><td>20</td></tr>
</table>

Example (result)

NameAge
Sara20

<thead>, <tbody>, <tfoot>, <caption>

Definition

These group the parts of a table: a header section, a body, a footer, and a title (<caption>) shown above the table.

Attributes

AttributeRole
(global)Only global attributes; styling is done with CSS.

Example (code)

<table>
  <caption>Students</caption>
  <thead><tr><th>Name</th></tr></thead>
  <tbody><tr><td>Ali</td></tr></tbody>
</table>

Example (result)

Students
Name
Ali

Definition

Attributes

AttributeRole
colspanNumber of columns the cell covers.

Example (code)

<tr><td colspan="2">Merged cell</td></tr>
