Lists

HTML offers unordered lists, ordered lists and description lists.

<ul> and <li>

Definition

An unordered list shows items with bullet points. Each item is a <li>.

Attributes

AttributeRole
(global)Bullet style is set with CSS (list-style-type).

Example (code)

<ul>
  <li>Apple</li>
  <li>Banana</li>
</ul>

Example (result)

  • Apple
  • Banana

<ol> and <li>

Definition

An ordered list numbers its items automatically.

Attributes

AttributeRole
typeNumbering style: 1, A, a, I, i.
startThe number the list starts counting from.
reversedCounts down instead of up.

Example (code)

<ol type="1" start="1">
  <li>First</li>
  <li>Second</li>
</ol>

Example (result)

  1. First
  2. Second

<dl>, <dt>, <dd>

Definition

A description list pairs terms (<dt>) with their descriptions (<dd>).

Attributes

AttributeRole
(global)Only global attributes.

Example (code)

<dl>
  <dt>HTML</dt>
  <dd>The language of web pages.</dd>
</dl>

Example (result)

HTML
The language of web pages.

Nested lists

Definition

A list can contain another list inside an <li> to build sub-levels.

Attributes

AttributeRole
(global)Only global attributes.

Example (code)

<ul>
  <li>Fruit
    <ul><li>Apple</li></ul>
  </li>
</ul>

Example (result)

  • Fruit
    • Apple
