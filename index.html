Welcome

This website reviews the main HTML tags. Each page explains one family of tags with three parts: a Definition, a table of Attributes, and an Example shown twice — once as code and once as the real result in the browser. Use the menu above to navigate.

<!DOCTYPE html>

Definition

The document type declaration. It is the very first line of a page and tells the browser to use the modern HTML5 standard.

Attributes

AttributeRole
(none)<!DOCTYPE html> has no attributes; it is just a declaration.

Example (code)

<!DOCTYPE html>
<html lang="en"> ... </html>

Example (result)

This whole page starts with <!DOCTYPE html> — view the source to see it.

<html>

Definition

The root element that wraps all the content of the page. Everything else lives inside it.

Attributes

AttributeRole
langDeclares the language of the document (e.g. en, fr).
dirText direction: ltr (left-to-right) or rtl.

Example (code)

<html lang="en">
  <head> ... </head>
  <body> ... </body>
</html>

Example (result)

The <html lang="en"> element contains this entire document.

<head>

Definition

A container for information about the page (metadata): title, character set, links to stylesheets. Its content is not shown in the page body.

Attributes

AttributeRole
(none)The <head> element has no specific attributes.

Example (code)

<head>
  <meta charset="UTF-8">
  <title>My Page</title>
  <link rel="stylesheet" href="css/style.css">
</head>

Example (result)

The title in your browser tab and the styles of this page come from the <head>.

<body>

Definition

The container for all the visible content of the page: text, images, links, tables and everything the user sees.

Attributes

AttributeRole
(global)Uses global attributes such as id, class, lang. Presentational attributes are replaced by CSS.

Example (code)

<body>
  <h1>Hello</h1>
  <p>Visible content goes here.</p>
</body>

Example (result)

Hello
Visible content goes here.
