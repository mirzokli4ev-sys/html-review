Multimedia

These tags embed audio, video and other web pages inside your page.

<audio>

Definition

Embeds a sound file with play, pause and volume controls.

Attributes

AttributeRole
srcPath of the audio file (or use <source> inside).
controlsShows the play/pause interface.
autoplayStarts playing automatically (use with care).
loopRepeats the audio when it ends.

Example (code)

<audio controls>
  <source src="images/song.mp3" type="audio/mpeg">
  Your browser does not support audio.
</audio>

(Add an images/song.mp3 file to hear it play.)

<video> and <source>

Definition

Embeds a video player. <source> lets you offer several file formats.

Attributes

AttributeRole
controlsShows player controls.
width / heightSize of the video area.
posterImage shown before the video plays.
mutedStarts without sound.

Example (code)

<video controls width="320" poster="images/sample.jpg">
  <source src="images/clip.mp4" type="video/mp4">
  Your browser does not support video.
</video>

Example (result)

(The poster image shows; add images/clip.mp4 to play a video.)

<iframe>

Definition

Embeds another web page (for example a map or a YouTube video) inside the current page.

Attributes

AttributeRole
srcURL of the page to embed.
width / heightSize of the frame.
titleAccessible description of the frame.
allowfullscreenLets the embedded content go full screen.

Example (code)

<iframe src="https://example.com"
        width="320" height="180" title="Example site"></iframe>
